# Codex Prompt: Implement Visual Web Upgrade

Task: Upgrade the current web project using the Visual Web AI Skillpack.

Process:
1. Inspect the project tree.
2. Identify framework, package manager, build scripts, style system, routes, and components.
3. Create a concise plan.
4. Implement only safe, incremental improvements first:
   - Layout hierarchy
   - Typography scale
   - CTA clarity
   - Responsive spacing
   - Motion primitives
   - Accessibility fixes
   - Image/font optimization
5. Add optional advanced 3D/motion behind a feature flag or lazy-loaded component.
6. Run build/lint/tests.
7. Report exact files changed.

Hard constraints:
- No copyrighted visual cloning.
- Do not add paid dependencies unless explicitly approved.
- Respect prefers-reduced-motion.
- Keep mobile performance strong.
