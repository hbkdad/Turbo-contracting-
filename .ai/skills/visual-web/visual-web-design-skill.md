# Skill: Visual Web Design Direction

Use when improving or designing a website, landing page, SaaS dashboard, portfolio, local business site, or 3D/motion interface.

## Operating mode
1. Identify the business goal.
2. Define the visitor action.
3. Build a visual system before adding effects.
4. Use motion only when it improves hierarchy, orientation, emotion, or conversion.
5. Test performance and accessibility before shipping.

## Visual system checklist
- Typography scale: display, headline, subhead, body, caption
- Colour tokens: background, surface, border, text, accent, danger, success
- Spacing: 4/8px scale, large editorial section rhythm
- Components: nav, hero, proof, services, process, gallery, CTA, footer
- Imagery: real photos, 3D renders, diagrams, texture overlays
- Motion: page reveal, section reveal, hover feedback, scroll progress, modal transitions

## Output required
Return:
- Design diagnosis
- Visual direction
- Component list
- Animation plan
- Implementation notes
- Performance/accessibility risks
