# Technical SEO Skill

Use this skill when auditing or fixing site foundations.

## Tasks
- Generate sitemap.xml.
- Generate robots.txt.
- Check canonical tags.
- Check missing alt text.
- Check heading hierarchy.
- Check duplicate metadata.
- Check broken internal links.
- Check mobile viewport.
- Check lazy loading.
- Check image compression.
- Check Core Web Vitals risks.
- Check index/noindex tags.
- Check redirect issues.

## Output Format
Create:
- `TECHNICAL-SEO-FIXES.md`
- `robots.txt`
- `sitemap.xml`
- `SEO-IMPLEMENTATION-CHECKLIST.md`
