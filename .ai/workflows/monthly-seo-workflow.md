# Monthly SEO Workflow

## Prompt
Run monthly SEO maintenance for this client website.

## Monthly Tasks
1. Review Search Console queries and pages.
2. Identify pages losing impressions or clicks.
3. Update metadata where CTR is weak.
4. Add internal links to priority pages.
5. Publish 2-4 support articles.
6. Add 1 new FAQ section to a service page.
7. Update GBP posts weekly.
8. Request reviews from recent customers.
9. Check index coverage.
10. Check broken links and performance.

## Outputs
- MONTHLY-SEO-REPORT.md
- NEXT-MONTH-ACTION-PLAN.md
