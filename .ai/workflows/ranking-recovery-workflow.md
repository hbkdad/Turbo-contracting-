# Ranking Recovery Workflow

Use when traffic or rankings drop.

## Steps
1. Confirm date of drop.
2. Compare changed pages.
3. Check indexing.
4. Check robots/noindex/canonical mistakes.
5. Check Core Web Vitals changes.
6. Check lost backlinks if data is available.
7. Check content quality and intent match.
8. Check SERP changes.
9. Create recovery tasks.

## Output
- RANKING-RECOVERY-REPORT.md
