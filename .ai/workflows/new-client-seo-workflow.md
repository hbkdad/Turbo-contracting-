# New Client SEO Workflow

Use this workflow when starting a new website or SEO project.

## Prompt
Read the client website/project files. Create a complete SEO foundation package.

## Steps
1. Identify business type, services, locations, audience, and conversion goals.
2. Audit technical SEO.
3. Create keyword map.
4. Create metadata sheet.
5. Create schema files.
6. Create Local SEO plan.
7. Create Google Business Profile content.
8. Create service page briefs.
9. Create 90-day content cluster plan.
10. Create implementation tasks for Codex/Claude Code.

## Outputs
- SEO-AUDIT.md
- SEO-ROADMAP.md
- KEYWORD-MAP.csv
- METADATA.csv
- LOCAL-SEO-PLAN.md
- GBP-OPTIMIZATION.md
- CONTENT-CLUSTER-PLAN.md
- SCHEMA files
