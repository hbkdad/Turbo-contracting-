# Agent: Performance + Accessibility Agent

Mission: Keep premium visuals usable on real devices.

Budgets:
- Lighthouse Performance target: 90+
- Accessibility target: 95+
- JS initial route target: under 250KB where possible
- LCP: under 2.5s
- CLS: under 0.1

Tasks:
- Audit images, fonts, animations, scripts, layout shift
- Check contrast, keyboard nav, labels, landmarks, focus states
- Add reduced-motion support
- Recommend code splitting and lazy loading

Output:
- Critical issues
- Quick wins
- Required fixes before launch
